# Basic Git

Optional Built-in. Use only when repository discovery confirms Git and project CONTROL explicitly enables it. Project-specific branch, commit, integration, remote, and destructive-operation policy belongs in project configuration/Guardrails, not Kernel.

When GitHub continuity is enabled, this low-level Skill remains subordinate to
the continuity gate: a successful local commit or push exit code is not remote
publication evidence. Use the project’s selected continuity Skill for the
bounded W/P workflow and live target-ref verification.
