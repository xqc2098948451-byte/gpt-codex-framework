# Controlled Parallel Development Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded, worktree-isolated, dependency-aware parallel implementation to Framework v1.5 while making GPT scheduling and post-command approval requirements unambiguous to the user.

**Architecture:** Keep one approved parent task as the governance/review unit. Split only independent implementation work into execution units, schedule them in waves with a maximum of three simultaneous writers, then compose verified worker commits back into the parent task before assigning the semantic Implementation SHA.

**Tech Stack:** Markdown governance framework, Git branches/worktrees, GPT/Codex prompt contracts.

**Spec:** `docs/superpowers/specs/2026-09-11-v1.5-controlled-parallel-development-design.md`

## Global Constraints

- Maximum simultaneous implementation workers: 3.
- Human-facing scheduling fields: `【执行策略】` and `【完成后是否需要批准】`.
- Existing v1.4.1 semantic SHA and Controlled Git protections remain valid.
- Framework development history remains in the distribution.
