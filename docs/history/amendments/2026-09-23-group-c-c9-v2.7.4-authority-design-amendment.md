## 7. Native execution, publication, and finalization separation

Every mutation Work Unit requires its own later authority:

```text
Work Unit integrated
-> native EXECUTION_INSTRUCTION
-> independent PRE_EXECUTION review
-> GPT adjudication
-> CODEX_IMPLEMENTER bounded mutation
-> independent POST_EXECUTION review
```

No Work Unit or bootstrap self-authorizes implementation. CODEX_IMPLEMENTER never receives `COMMIT`, `PUSH`, or `PUBLISH`. Git transport is USER_LOCAL only where explicitly approved. Remote publication is separately governed USER_LOCAL action.

Publication is forbidden before exact USER acceptance, before fresh capability/preflight checks, or for another candidate. `TAG_WRITE`, `RELEASE_WRITE`, and `ASSET_UPLOAD` are later observations, not current claims.

Finalization is strictly post-publication. It records independently observed facts and must not claim the finalization commit caused publication. It cannot mutate source, package artifacts, tag, GitHub Release, asset, `VERSION`, release record, or release index. Its candidate requires independent review, GPT adjudication, and exact USER acceptance before USER_LOCAL integration.
