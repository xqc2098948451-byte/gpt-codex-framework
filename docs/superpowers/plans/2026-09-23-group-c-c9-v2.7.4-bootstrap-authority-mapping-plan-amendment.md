## 7. Replay and failures

Instantiate Release 002, Packaging 002, and Finalization 001 bootstrap
mappings twice with identical concrete dummy SHA values. Reconstruct authority
subobjects from reverse-insertion input mappings. The builder itself constructs
the stated order, therefore byte output and SHA-256 must match exactly:

```text
RELEASE_BOOTSTRAP_002_REPLAY = PASS
PACKAGING_BOOTSTRAP_002_REPLAY = PASS
FINALIZATION_BOOTSTRAP_001_REPLAY = PASS
BOOTSTRAP_AUTHORITY_MAPPING_DETERMINISM = PASS
BOOTSTRAP_FIELD_ORDER_DETERMINISM = PASS
```

```text
bootstrap field set differs -> REVIEW_FINDING
accepted_* references historical rather than current authority -> FAIL
current controlling Plan duplicated in base_plan_refs -> FAIL
base_plan_refs unordered or incomplete -> REVIEW_FINDING
unresolved SHA -> RECONCILIATION_REQUIRED / freeze forbidden
old 001 bootstrap reuse -> FORBIDDEN
generic bootstrap factory authority -> FORBIDDEN
```

Before any actual freeze, every runtime SHA is concrete; no symbolic marker is
canonical content.
