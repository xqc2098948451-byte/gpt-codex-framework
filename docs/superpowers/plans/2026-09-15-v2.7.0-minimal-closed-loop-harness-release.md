# v2.7.0 Minimal Closed-Loop Harness Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release the accepted minimal closed-loop harness implementation as Framework v2.7.0 through a separately reviewed candidate, authorized publication, remote verification, and management-only attestation.

**Architecture:** The existing release pipeline remains the only candidate-artifact producer. A dedicated release branch produces a candidate work commit (W); an independent review accepts that immutable commit before it is integrated to `main`. Publication is a separate user-authorized operation targeting W, and a later management-only publication attestation (P) may be created only after independently observed remote verification.

**Tech Stack:** Python 3 standard library release and validation scripts, JSON release records and evidence, Git/GitHub, unittest.

**Spec:** `ba40be545b6727d6d89dd7f11cc2f5df7b2f84c9:docs/superpowers/specs/2026-09-15-v2.7.0-minimal-closed-loop-harness-release-design.md` (immutable).
