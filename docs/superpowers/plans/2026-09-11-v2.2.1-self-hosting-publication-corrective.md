# GPT–Codex Framework v2.2.1 Self-Hosting and Publication Corrective Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task with verification checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local-only v2.2.1 corrective release that adds narrowly scoped Framework Management self-hosting validation and mechanically rejects contradictory publication authority claims.

**Architecture:** Extend the existing Python standard-library validators and Schema generation 1 conditionals. Keep the existing bounded Git continuity model, add a small publication-contract decision module for cross-field/evidence checks, and make resume compare verified generic baseline W with management attestation head P. Update only the current release metadata and artifacts after all tests are green.

**Tech Stack:** Python 3 standard library, `unittest`, JSON Schema draft 2020-12-shaped files, deterministic ZIP packaging, Git read-only verification.

**Spec:** `docs/superpowers/specs/2026-09-11-v2.2.1-self-hosting-publication-corrective-design.md`

## Global Constraints

- `VERSION = 2.2.1`.
- `KERNEL_VERSION = 2.0.0`.
- `SCHEMA_VERSION = 1`.
- Frozen v2.2.0 ZIP SHA-256 is `a637a48382a32c28db106263a385e5d3c902dff8b28c2387864fb5c6b80ff8d3` and its contents must not change.
- Remote `refs/heads/main` must remain `954221c75aca086a901294e26207e3ddd5c189a7`.
- No `git push`, GitHub API write, ref update, remote branch creation, PR, release creation, or history rewrite.
- `status == PASS` requires `remote_verification == VERIFIED`.
- `sync_status == SYNCED` requires verified publication evidence.
- `PUBLICATION_CANDIDATE_ONLY` cannot coexist with `PASS`, `SYNCED`, or authoritative `COMPLETE`.
- `COMPLETE` requires durable verified Result/Evidence, and synced STATE requires non-empty `latest_verified_remote_sha` tied to that evidence.
- Before W is remotely verified, the only valid local result is `LOCAL_COMPLETE`/`SYNC_PENDING` with candidate authority and a non-final state.
- Ordinary consumers retain `governance_profile` in `MINIMAL`, `STANDARD`, or `EXTENDED` and `roots.framework_role == ADVISORY`.
- Management builtin installed-path omission is allowed only for cataloged builtin IDs when `framework_management_only == true`.
- The work ends with `RESULT: LOCAL_COMPLETE`, `SYNC_STATUS: SYNC_PENDING`, `GITHUB_WRITE_PERFORMED: NO`, and `PUSH_STATUS: NOT_ATTEMPTED`.
