# Project Adaptation Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit framework-defaults versus project-parameters adaptation layer without weakening existing v1.5 safety mechanisms.

**Architecture:** Keep the universal framework as the invariant/default authority and make approved `PROJECT.md` the location for project-specific parameter selections. Bootstrap GPT performs the adaptation; Codex consumes the approved project values.

**Tech Stack:** Markdown governance artifacts and static distribution validation.

**Spec:** `docs/superpowers/specs/2026-09-11-v1.5.1-project-adaptation-model-design.md`

- Preserve all v1.5 Controlled Parallel Development behavior.
- Preserve v1.4.1 semantic Implementation SHA behavior.
- Preserve complete framework development history.
- Normal parallel hard ceiling remains 3.
- No business-project migration.
