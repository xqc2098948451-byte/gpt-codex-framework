# v2.0.2 Lightweight Release Archive Implementation Plan

**Goal:** Add metadata-only historical release archiving and automatic current-release cleanup without changing the v2.0 Kernel Contract.

**Architecture:** Extend the existing management-only `framework-release` Skill with a small standard-library archive helper. Historical ZIPs are inputs used to create metadata records, never contents of future release packages.

**Tech Stack:** Python standard library, JSON, ZIP, SHA-256.

**Spec:** `docs/superpowers/specs/2026-09-11-v2.0.2-lightweight-release-archive-design.md`
