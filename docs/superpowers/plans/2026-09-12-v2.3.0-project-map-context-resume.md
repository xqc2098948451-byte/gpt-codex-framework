# v2.3.0 Project Map + Context Checkpoint + Delta Resume Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent derived Project Map and checkpoint-first resume protocol so normal maintenance starts from a compact navigation index and reads only relevant modules/files instead of rediscovering or rereading the whole repository.

**Architecture:** Introduce a two-level navigation index under `.gpt-codex/navigation/` and keep resume state under `.gpt-codex/continuity/RESUME.json`. Add a focused `project_navigation.py` helper for identity/freshness/path impact, extend existing `continuity_resume.py` for hot modules and delta resume, and change Bootstrap/Repository Discovery/Handoff so maintenance follows `identity → map → resume → relevant delta → targeted reads`.

**Tech Stack:** Python 3 standard library, `unittest`, JSON contracts/templates, existing GPT–Codex validation/release tooling.

**Spec:** `docs/superpowers/specs/2026-09-12-v2.3.0-project-map-context-resume-design.md`

## Global Constraints

- Framework baseline before implementation: `2.2.1`.
- Preferred Kernel version remains `2.0.0`.
- Preferred schema generation remains `1`.
- `PROJECT_MAP.json` and module maps are `DERIVED_NAVIGATION_INDEX`, never project/source authority.
- `RESUME.json` is `DERIVED_CACHE`, never project/source authority.
- Existing `CONTROL.json`, `STATE.json`, Work Units, Evidence, Result Envelopes, source/test files, Git and GitHub facts retain their existing authority.
- A context-window transition is not a project bootstrap.
- A maintenance request is not a repository rediscovery.
- Do not scan the repository when the Project Map can identify the candidate module.
- Do not run repository-wide discovery for a valid checkpoint/map maintenance path.
- Existing v2.2.1 projects without navigation or resume files remain valid.
- Natural-language map matching is performed by GPT from compact semantic fields; do not add vector databases, embeddings, external search services, or NLP dependencies.
- Map updates are incremental by affected module; do not globally rebuild the map after every edit.
- Repository Discovery remains read-only.
- Handoff remains read-only.
- Tests precede implementation changes.
- Do not modify unrelated framework behavior.

def load_project_map(root: Path) -> dict[str, Any] | None:
    path = Path(root) / PROJECT_MAP_RELATIVE
    if not path.is_file():
        return None
    payload = _load_json(path)
    if payload.get("schema_version") != 1:
        raise ValueError("NAVIGATION_SCHEMA_UNSUPPORTED")
    if payload.get("authority") != "DERIVED_NAVIGATION_INDEX":
        raise ValueError("NAVIGATION_AUTHORITY_INVALID")
    module_ids = [
        item.get("id")
        for item in payload.get("modules") or []
        if isinstance(item, dict)

    if len(module_ids) != len(set(module_ids)):
        raise ValueError("NAVIGATION_DUPLICATE_MODULE_ID")
    return payload

- [ ] **Step 4: Implement normalized path matching**

```python
from pathlib import PurePosixPath


def _normalise_relative(value: str) -> str:
    return PurePosixPath(value).as_posix().lstrip("./")


def path_belongs_to_module(path: str, module: dict[str, Any]) -> bool:
    candidate = _normalise_relative(path)
    for raw_prefix in module.get("paths") or []:
        prefix = _normalise_relative(raw_prefix).rstrip("/")
        if candidate == prefix or candidate.startswith(prefix + "/"):
            return True
    return False
```

- [ ] **Step 5: Implement affected-module calculation**

```python
def affected_modules(
    project_map: dict[str, Any],
    changed_paths: list[str],
) -> list[str]:
    affected = set()
    for module in project_map.get("modules") or []:
        if not isinstance(module, dict):
            continue
        if any(path_belongs_to_module(path, module) for path in changed_paths):
            module_id = module.get("id")
            if isinstance(module_id, str):
                affected.add(module_id)
    return sorted(affected)
```

- [ ] **Step 6: Implement route classification**

```python
def classify_map_route(
    candidate_module_ids: list[str],
    stale_module_ids: list[str],
    *,
    map_exists: bool = True,
) -> str:
    if not map_exists:
        return "MAP_MISSING"
    if not candidate_module_ids:
        return "MAP_MISS"
    if set(candidate_module_ids) & set(stale_module_ids):
        return "MAP_PARTIAL"
    return "MAP_HIT"
```
