The canonical source identity and content-set algorithm is fixed:

```python
def canonical_source_identities(raw):
    if set(raw) != set(RELEASE_SOURCE_PATHS):
        raise ValueError("SOURCE_IDENTITIES_PATH_SET_MISMATCH")
    result = []
    for path in RELEASE_SOURCE_PATHS:
        value = raw[path]
        if set(value) != {"sha256", "git_blob_sha1"}:
            raise ValueError("SOURCE_IDENTITY_SHAPE_MISMATCH")
        result.append({
            "path": path,
            "sha256": require_sha256(value["sha256"], "INVALID_SOURCE_SHA256"),
            "git_blob_sha1": require_sha40(value["git_blob_sha1"], "INVALID_SOURCE_GIT_BLOB_SHA1"),
        })
    return result

def canonical_source_content_set_bytes(raw):
    return (json.dumps(canonical_source_identities(raw), ensure_ascii=False,
                       sort_keys=True, indent=2) + "\n").encode("utf-8")

def source_content_set_sha256(raw):
    return hashlib.sha256(canonical_source_content_set_bytes(raw)).hexdigest()
```

Forward and reverse input insertion order must produce byte-identical content
and the same digest. Every future Packaging and Finalization authority uses
this seven-source form.
